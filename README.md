# GTA 네온 하버 ONLINE — 새로 배포하기

이 저장소에는 **파일 4개만** 있으면 됩니다. 폴더는 없습니다.

| 파일 | 역할 |
|---|---|
| `worker.js` | 게임 화면(HTML·CSS·JS) + 멀티플레이 서버(방·채팅·동기화)가 모두 들어 있는 파일 |
| `wrangler.json` | Cloudflare 설정 (Durable Object `GameRoom`, SQLite 저장소) |
| `package.json` | 배포 도구(wrangler) 버전 |
| `README.md` | 이 설명서 |

## 1. GitHub 저장소 만들기
1. github.com → 오른쪽 위 **+** → **New repository**
2. Repository name: **`neon-harbor`** → **Create repository**
3. 나온 화면에서 **uploading an existing file** 클릭
4. 파일 4개(`worker.js`, `wrangler.json`, `package.json`, `README.md`)를 한꺼번에 끌어다 놓기 → **Commit changes**
5. 저장소 첫 화면에 파일 4개가 **나란히** 보이면 성공

## 2. Cloudflare에 연결
1. dash.cloudflare.com → 왼쪽 **Workers & Pages** (Compute) → **Create application**
2. **Import a repository** (Git 저장소 가져오기) → GitHub 연결 → **`neon-harbor`** 선택
3. 설정 화면에서
   - **Project name**: `neon-harbor` (wrangler.json 의 name 과 같아야 함)
   - **Build command**: 비워 두기
   - **Deploy command**: `npx wrangler deploy`
   - **Root directory / Path**: 비워 두기 (또는 `/`)
4. **Create and deploy** (배포하기)

1~2분 뒤 `https://neon-harbor.<내계정>.workers.dev` 주소가 생깁니다. 이 주소가 **게임 주소**입니다.

## 3. 확인
- 게임 주소 → 로비(닉네임 · 방 만들기 · 방 코드로 참가)가 나오면 성공
- `게임주소/api/health` → `{"ok":true,...}` 가 나오면 서버도 정상
- 친구에게는 게임 주소나, 방을 만든 뒤 나오는 **초대 링크**를 보내면 됩니다.

## 방 만들기 · 방 찾기
- **방 만들기**: 방 제목 · **공개 / 비공개** · **닉네임 보이기 / 숨기기** · 최대 인원 **2~8명** · PvP 여부를 정하고 만들기
  - 공개 방: **방 찾기** 목록에 보이고 누구나 들어올 수 있음
  - 비공개 방: 목록에 안 보임 · 처음 화면의 **초대 코드로 참가** 칸에 코드를 넣어야만 입장
  - 닉네임 숨기기: 게임 속 다른 플레이어 머리 위 이름표가 사라지고, 방 찾기 목록에도 방장 이름이 "방장 비공개"로 표시됨 (채팅 · 접속자 목록에는 이름이 그대로 보임) · 게임 중에 방장이 `/names on` · `/names off` 로 바꿀 수 있음
- **방 찾기**: 지금 사람이 있는 공개 방 목록 (6초마다 자동 새로고침) → **참가**
- 방 코드는 시작 화면에서 복사하거나, 게임 중 채팅에 `/code` 를 입력해서 볼 수 있음
- 아무도 없는 방은 15분 뒤 자동으로 사라짐

## 조작
- `Enter` 채팅 (채팅창은 왼쪽 아래에 항상 보임) · `Tab` 접속자 목록 · 나머지는 원작과 같음
- `T` 는 원작의 **인질** 키라서 채팅은 `Enter` 로만 엽니다 · 휴대폰은 **채팅** 버튼
- 채팅 명령어: `/help` · `/who` · `/code` · `/nick 새닉네임` · 방장 전용 `/pvp on|off` · `/names on|off`

## 오류가 나면
| 로그 내용 | 해결 |
|---|---|
| `entry-point file ... was not found` | 저장소 맨 위에 `worker.js` 가 있는지, Root directory 가 비어 있는지 확인 |
| `name` 이 다르다는 오류 | `wrangler.json` 의 `"name"` 을 Cloudflare 프로젝트 이름과 똑같이 맞추기 |
| `exports` / Durable Object 관련 오류 | 로그 전체를 복사해서 문의 |

## 온라인에서 함께 되는 것 (최신 원작 기준)
- 같은 도시 · 같은 시각, 다른 플레이어의 이름표 · 자세 · 무기(저격총 · 테이저건 포함) · 탄 차량(전차 · 요격기 · 경비정 포함)
- 총소리 · 총알 궤적 · 화염병 · RPG · **전차 포탄** · 헬기/요격기/장갑차 기관포 궤적
- PvP 방: 총 · 주먹 · 화염병 · RPG · 전차포 · 차량 기관포로 서로 피해 · **방탄조끼**는 다른 플레이어의 총알도 막아 줌
- PvP 방: 다른 플레이어의 **테이저건**에 맞으면 4초 동안 움직일 수 없음 (차 안에서는 안 맞음)
- PvP 방: **저격총**은 원작 규칙 그대로 머리 1~3방 · 몸통 4~7방에 쓰러짐 (방탄조끼 무관, 헤드샷 알림)
- 시민 · 경찰 · 군대 · 교통은 각자 화면에서 따로 움직이고, 돈 · 무기 · 수배는 각자의 것

## 업데이트 건의 게시판
메인 화면의 큰 **업데이트 건의하기** 버튼 → 누구나 닉네임(비우면 익명)과 건의 내용(최대 500자)을 올릴 수 있음
- 최신 글부터 30개씩, **더 보기**로 이전 글
- 도배 방지: 한 사람당 10분에 3개 · 같은 내용 하루 1번 · 전체 10분에 60개 (접속 주소는 저장하지 않고 되돌릴 수 없는 값으로만 비교)
- 글은 최근 500개까지 보관
- **개발자 모드를 켠 상태로 게시판에 들어가면** 글마다 답변 칸이 생겨 **답변 등록 · 수정 · 삭제**를 할 수 있고, 글 삭제도 가능 (삭제는 두 번 눌러야 됨)
- 답변이 달린 글은 초록색 "답변 완료" 표시와 함께 모두에게 보임

## 개발자 모드 (운영자 전용)
메인 화면(로비) **오른쪽 아래 구석의 작은 `개발자 모드` 버튼** → 개발자 코드 입력 → **활성화**

| 탭 | 할 수 있는 일 |
|---|---|
| 공지 | 내용(최대 300자) · 지속 시간(초/분/시간) · 띄울 곳을 정해 보내기<br>· **모든 방의 게임 화면 위쪽 배너**: 지금 게임 중인 모든 방에 바로 뜸, 남은 시간 표시, 나중에 들어온 사람에게도 보임<br>· **메인 화면 큰 팝업**: 로비를 연 사람에게 크게 뜸 (확인을 누르면 닫힘)<br>· **지금 내리기**로 즉시 종료 |
| 방 · 플레이어 | 모든 방 목록(비공개 방 포함) → 방을 골라 **방 이름 변경**, 접속 중인 **플레이어 닉네임 변경** (방 안 채팅에 운영자 변경 알림이 남음) |

보안
- 개발자 코드는 **서버에서만** 확인합니다. 게임 화면 코드(브라우저)에는 코드가 들어 있지 않아요.
- `worker.js` 안에도 코드 원문은 없고, 되돌릴 수 없는 해시만 들어 있습니다.
- 틀린 코드를 5번 입력하면 그 접속 주소는 10분 동안 잠깁니다.
- 로그인은 12시간 유지되고, 브라우저 탭을 닫으면 풀립니다.
- **GitHub 저장소는 Private(비공개)로 두는 것을 권장합니다.**
- 코드를 바꾸려면: Cloudflare 대시보드 → 이 Worker → **Settings → Variables and Secrets → Add** → 종류 **Secret**, 이름 `ADMIN_CODE`, 값에 새 코드 → 저장. 그 뒤로는 새 코드만 통합니다.

## 업데이트하는 방법
이미 배포해 두었다면 GitHub 저장소에서 **Add file → Upload files** 로 새 `worker.js` 를 올리고 Commit 하면 자동으로 다시 배포됩니다. (`wrangler.json` · `package.json` 은 그대로 두어도 됨)

## 무료 플랜
Durable Objects 는 SQLite 저장소만 사용하므로 Workers 무료 플랜에서 동작합니다. 위치 정보는 움직일 때 초당 10회, 가만히 있을 때 초당 1회만 보내 무료 한도를 아낍니다.
